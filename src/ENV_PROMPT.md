# Web 搜索环境

你可调用 `web_search` 在网上搜索，返回标题、网址和简介；每条结果带提供商名（如 `[bocha]`），供 bot 在回答里引用。

## 什么时候调用

- 使用者问的事你本身不知道，或需要按最新信息回答（新闻、价格、文档、技术细节）。
- 需要核实某个事实，或给出的答案要附来源。

## 如何引用

每条结果自带标题、网址和提供商名。回答时，在引用的句子后紧跟网址，或列出来源清单，让人能按网址打开看原文。不要编造网址，也不要把搜索结果当成你自己的知识概括而不标来源。

## 不要滥用

- 不要为已知的常识、不需要时效性的事实，或已在对话里给出的答案再搜一次。
- 一次搜索最多返回 10 条，取够用的即可，不要反复搜同一个关键词。

密钥由宿主的 secrets 注入，不要把密钥写入配置文件明文。各提供商的密钥名、价格与硬约束见面板提示（`PROVIDER_HINTS`）。

## 提供商提示（价格为官方量级参考，随官方变动）

- anysearch：免费 1000 次/天，API + MCP + Skill，个人项目与原型首选；匿名访问受较低限速，建议配 API key。
- tavily：$8/千次（1000 credits/月免费），Agent 默认项，含 extract/crawl/map；密钥必填，无匿名访问。
- exa：$7/千次（快速模式 $4），向量语义检索，擅长探索式查询；密钥必填，以 x-api-key 头传递。
- bocha：约 ¥20/千次，中文场景综合最强，自带 reranker，0.15s 延迟；密钥必填，中文搜索为主。
- ali（阿里 IQS）：约 ¥12/千次 Lite，Standard ¥30–42，Deep ¥50，有 OpenAI 兼容格式；密钥必填，付费后付费。
- tencent：约 ¥18–22/千次轻量版后付费；密钥必填，需腾讯云账号。
- zhipu：含在 token 费用内，Tool Calling + MCP，聚合 5 家引擎；密钥必填，随模型账单计费。
- perplexity：$5/千次，原始结果，索引新、覆盖广；密钥必填，Sonar 异步接口已停止支持。
- serper：$0.3–1/千次，最便宜的 Google SERP，无正文提取；密钥必填，合规风险自评。
- brave：$5/月免费额度，自有索引约 300 亿页，不依赖 Google/Bing；密钥必填，免费额度有限。

## 硬约束

- Bing Search API 已关停，替代品 Grounding with Bing 只返回模型答案，不给原始结果。
- Google Custom Search JSON API 已停止接受新客户，存量客户 2027-01-01 过渡截止。
- SERP 抓取类存在法律尾部风险（如 SerpApi、Reddit 相关诉讼，未结案），合规风险自评。
- 只用一个供应商是架构缺陷：保留第二套备用检索方案，并编写降级逻辑。本插件已对各提供商并行调用并按 url 去重，任一失败自动跳过。
